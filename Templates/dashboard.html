Инструкция по установке

1. Подключите скрипт

Вставьте перед закрывающим тегом </body>:


            


            
            

                
2. Разметьте секции для отслеживания просмотров

                
Добавьте атрибуты data-track к секциям страницы:

                
<section data-track="section" data-track-name="hero">
  ...контент секции...
</section>

            


            
            

                
3. Разметьте кнопки/ссылки для событий кликов

                
<button data-track="click"
        data-track-event="cta_click"
        data-track-name="hero_cta">
  Купить сейчас
</button>

            


            
            

                
4. Разметьте формы

                
<form data-track="form"
      data-track-event="form_submit"
      data-track-name="booking_form">
  ...поля формы...
</form>

            


            
            

                

                    Примечание: Тепловая карта кликов собирается автоматически для всех кликов на странице. 
                    Атрибуты data-track нужны для именованных событий и секций.
